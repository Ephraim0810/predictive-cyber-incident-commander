# Synthesis workspace

Only the synthesis lead writes here after a task's review gate accepts its `handoff_packet.md`. Create these deliverables:

- `evidence_matrix.md`: every architecture choice mapped to task claim IDs.
- `dataset_decision.md`: candidate dataset comparison, licence, temporal suitability, and selected route.
- `architecture_decision_record.md`: selected pipeline, interfaces, baselines, metrics, human approval boundary, and rejected alternatives.
- `contribution_statement.md`: one falsifiable technical contribution, novelty evidence, and evaluation plan.
- `research_gap_register.md`: unresolved gaps, owners, and whether they block implementation.

Never turn a task hypothesis into an architecture decision without a source ID or experiment ID.
